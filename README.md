# 发票自动下载管理器

一款基于 Python + Tkinter 开发的 Windows 桌面应用程序，用于自动从 QQ 邮箱扫描和下载发票附件。

## 主要功能

- **扫码下载**：选择“二维码交付”图片、粘贴截图（Ctrl+V）或输入下载链接，无需连接邮箱即可下载 PDF。支持税务数电发票交付二维码。
- **邮件扫描**：自动扫描 QQ 邮箱中的发票邮件，支持多种日期范围筛选（不限、今天、本周、本月、上月、前两月、前三月、前半年）
- **进度显示**：扫描过程实时显示进度条和扫描数量
- **取消扫描**：支持中途取消扫描任务
- **选择性下载**：支持预览邮件内容，选择性下载发票附件
- **批量操作**：支持全选、反选发票，批量删除发票
- **发票识别**：自动识别发票信息（金额、日期、税额等）
- **自动去重**：发票号与价税合计同时一致时保留一份；下载时跳过重复票，加载和重新识别后自动清理已有重复。
- **商品明细提取**：支持从发票中提取商品明细
- **自动更新**：启动时自动检查 GitHub 最新版本
- **系统托盘**：支持最小化到系统托盘
- **数据导出**：支持导出发票汇总信息

## 系统要求

- Windows 10/11 操作系统
- 无需安装 Python（已打包为 exe 可执行文件）

## 快速开始

1. 从 [Releases](https://github.com/Airplaneload/invoice_manager/releases/latest) 下载最新版 Windows ZIP 包并完整解压；也可以下载本仓库中的整个 `invoice_manager_gui` 文件夹
2. 进入文件夹，双击 `invoice_manager_gui.exe` 运行程序
3. 输入 QQ 邮箱地址和授权码
4. 点击"连接"按钮连接邮箱
5. 点击"扫描"按钮开始扫描发票邮件（可选择日期范围）
6. 扫描过程中可点击"取消"按钮终止扫描

## 配置说明

### QQ 邮箱授权码获取

1. 登录 [QQ 邮箱](https://mail.qq.com/)
2. 进入 设置 → 账户与安全
3. 找到 POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务
4. 开启 IMAP/SMTP 服务
5. 按提示发送短信获取授权码

### config.json 配置

程序目录下的 `config.json` 文件包含以下配置：

首次使用可以直接在界面填写邮箱和授权码，也可以将 `invoice_manager_gui/config.example.json` 复制为同目录下的 `config.json` 后填写。个人配置、授权码、发票文件和下载测试资料不应提交到仓库。

```json
{
    "email": "your_email@qq.com",
    "auth_code": "your_auth_code",
    "download_dir": "./invoices",
    "auto_download": false,
    "check_interval": 300
}
```

## 使用说明

### 扫码下载发票（v1.5.5）

1. 双击根目录的 `启动发票管理器.bat`，或直接运行 `invoice_manager_gui/invoice_manager_gui.exe`。
2. 点击顶部的 **扫码下载**。
3. 点击“选择二维码图片”，或复制二维码截图后在窗口中按 **Ctrl+V**。也可直接粘贴发票下载链接。
4. 检查保存目录，点击 **下载发票**。成功后可在发票列表查看、识别和报账。

请使用“二维码交付”页面的下载二维码；发票票面上用于查验的数字二维码不包含下载网址。需要登录或验证的交付平台，可使用窗口内的“浏览器打开”。

### QQ 下载修复（v1.5.5）

- 修复同日期、同商品文件重名引起的保存失败；不同文件自动添加编号，相同文件重复下载按成功处理，不覆盖原文件。
- 支持普通附件、内嵌或无文件名 PDF，以及 ZIP 中的 PDF。
- 解析邮件 HTML、QQ 链接包装、网页及 JSON 中的 PDF 下载地址；校验下载内容，避免把错误网页保存为 PDF。
- 下载使用独立的只读邮箱连接，避免与邮件预览、扫描共用连接；读取中断后重连重试。
- 失败邮件保持勾选，可以直接重试；下载进度与日志在主界面更新。

### 开发与回退

当前仓库仅提供原版打包程序，因此本次保留原界面及其功能，通过独立扩展接入修复。维护代码位于 `src/invoice_download.py` 和 `src/invoice_extensions.py`；运行版副本位于 `invoice_manager_gui/_internal/`。

`tools/build_patch.py` 使用 Python 3.12 重建程序入口，保留原 PyInstaller 模块及依赖；新增二维码依赖为 `zxing-cpp`。构建环境需要 `tools/python312/python.exe`（官方 Python 3.12.10 嵌入版）和 `tools/wheels/` 中的对应 Windows CPython 3.12 wheel。运行 `tools/python312/python.exe tools/build_patch.py` 可重新构建。日常运行无需安装 Python。

运行 `python tools/package_release.py` 可生成完整的 Windows 发布 ZIP 和 SHA-256 校验文件；脚本会排除个人配置、发票记录、日志和缓存，并检查本地邮箱及授权码未混入发布文件。原有 GitHub Releases 版本检查功能保留，发布新版本时应同步创建对应版本的 Release。

本地构建会将原程序备份为 `invoice_manager_gui/invoice_manager_gui.original.exe`。需要回退时，关闭新版后直接运行该备份即可。备份不随仓库分发；现有邮箱配置与发票目录保持使用原配置。

测试使用项目内的 `validation_downloads/`，其中的发票和诊断材料不应上传到代码仓库。自动化回归检查可运行 `python -m unittest discover -s tests -v`（依赖 requests、Pillow、zxing-cpp）。

### 日期筛选

程序支持按以下时间范围筛选邮件：
- **不限**：扫描所有邮件
- **今天**：只扫描今天的邮件
- **本周**：扫描本周（周一至今）的邮件
- **本月**：扫描本月（1日至今）的邮件
- **上月**：扫描上个月的邮件
- **前两月**：扫描前两个月的邮件
- **前三月**：扫描前三个月的邮件
- **前半年**：扫描前半年的邮件

### 发票列表操作

- **全选**：选中所有发票
- **反选**：反向选择（已选中的取消，未选中的选中）
- **删除**：删除选中的发票记录
- **清理重复**：检查整个发票列表，按“发票号＋价税合计”清理重复票，与搜索和勾选状态无关。程序加载发票、下载完成或重新识别后也会自动检查。

只有发票号和金额都完整且一致才去重；同金额但不同发票号、同发票号但金额不同的文件均保留。传统 8 位发票号码还需发票代码一致；识别不完整的文件保留，避免误清理。

清理时优先保留带有效付款截图的记录，付款截图不会删除，勾选状态合并保留。重复 PDF 移到原目录下的 `重复发票备份/时间_编号/`，其中 `恢复信息.json` 记录原位置、保留文件和原记录信息，需要时可手动恢复。备份目录不参与发票加载。备份失败时保留原文件和列表记录。

### 自动更新

程序启动时会自动检查 GitHub 是否有新版本发布，发现新版本时会提示用户下载。
